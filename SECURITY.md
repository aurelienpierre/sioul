# Security

Sioul keeps mail, passwords, health records and money in one place, so a security problem matters more here than in most programs.

## Reporting a problem

Please report it privately, through GitHub's own form: [Report a vulnerability](https://github.com/aurelienpierre/sioul/security/advisories/new) (the repository's Security tab). Only the maintainer sees it. Say what you found, how to see it happen, and which version or commit you used.

Please do not open a public issue for a security problem: other people's data could be exposed before a fix is out.

## Versions

Fixes go into the next release. The latest release is the one supported; an older one gets a fix only when the problem is grave and an update is not possible.
