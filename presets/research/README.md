# Where the presets came from

The research of 4 October 2026, one file per scope (`fr.json`, `ca.json`, `us.json`, `international.json`, `social.json`): each site's sign-in address with, in `checked`, what was seen when it was asked (answered, redirected, refused robots, confirmed by its own pages or by search). `sites.json`, beside this folder, is what Sioul reads; these files are notes for whoever updates it. `tools/check-presets.py` asks every address of `sites.json` again.
